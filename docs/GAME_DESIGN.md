# 픽셀 액션 RPG 게임 기획서 (가제: *Ashen Crown*)

> 중세 판타지 · 2D 픽셀 아트 · 탑다운 액션 RPG · Unity 제작
> 문서 버전: v0.1 (초안) / 작성일: 2026-11-24

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 탑다운 2D 액션 RPG |
| 테마 | 중세 판타지 |
| 플랫폼 | PC (1차), 이후 모바일/콘솔 검토 |
| 엔진 | Unity 2D (URP) |
| 아트 | 16x16 / 32x32 픽셀 아트 |
| 플레이 모드 | 싱글 플레이 (협동 멀티는 후속 확장 검토) |
| 핵심 재미 | **종족 × 클래스 조합**으로 만드는 나만의 캐릭터와 실시간 액션 전투 |

### 1.1 한 줄 소개
몰락한 왕국의 왕관을 둘러싼 전쟁 속에서, 종족과 클래스를 직접 골라 모험하며 영웅이 되거나 새로운 마왕이 되는 픽셀 액션 RPG.

### 1.2 디자인 필러
1. **조합의 재미**: 5종족 × 5클래스 = 25가지 시작 조합, 각각 고유한 플레이 느낌
2. **손맛 있는 전투**: 회피, 타이밍, 위치 선정이 중요한 실시간 액션
3. **탐험과 성장**: 던전/필드 탐험, 장비 수집, 스킬 트리 빌드
4. **종족별 서사**: 선택한 종족에 따라 달라지는 대사, 퀘스트, 세력 관계

## 2. 세계관

### 2.1 배경
대륙 **아르카디아**는 천 년간 **솔라리온 왕국**의 통치 아래 평화로웠으나, 왕이 후계자 없이 죽으면서 **왕관**이 사라진다. 왕관은 모든 종족의 맹약을 지키던 마법 유물이었고, 이를 잃은 대륙은 종족 간 불신과 전쟁에 빠진다. 동시에 북쪽 **균열의 땅**에서 마족의 군세가 다시 움직이기 시작한다.

### 2.2 주요 지역 (초안)
| 지역 | 분위기 | 주요 종족 |
|---|---|---|
| 솔라리온 왕도 | 성벽 도시, 시장, 길드 | 인간 |
| 실바넬 숲 | 거대한 고목, 안개, 요정 불빛 | 엘프 |
| 아이언후드 산맥 | 광산, 용광로, 지하 도시 | 드워프 |
| 붉은 평원 | 부족 야영지, 전투 투기장 | 오크 |
| 균열의 땅 | 화산, 검은 성채, 붉은 하늘 | 마족 |
| 잊혀진 지하 묘지 | 언데드 던전 (중립) | - |

## 3. 종족 (Race)

종족은 **기본 능력치 보정 + 패시브 1개 + 고유 액티브 1개**를 제공한다.

| 종족 | 컨셉 | 능력치 보정 | 패시브 | 종족 액티브 |
|---|---|---|---|---|
| **인간** | 균형, 적응력 | 전 능력치 +1 | **적응력**: 경험치 획득 +10% | **불굴의 의지**: 3초간 받는 피해 30% 감소 |
| **엘프** | 민첩, 마력 친화 | 민첩 +3, 지능 +2, 체력 -1 | **숲의 감각**: 이동 속도 +8%, 마나 재생 +15% | **바람의 걸음**: 짧은 거리 순간 이동 |
| **드워프** | 단단함, 장인 | 체력 +3, 힘 +2, 민첩 -2 | **강철 피부**: 물리 방어 +10%, 넉백 저항 | **용광로 심장**: 5초간 체력 지속 회복 |
| **오크** | 야성, 근력 | 힘 +4, 체력 +1, 지능 -2 | **전사의 피**: 체력 30% 이하일 때 공격력 +20% | **분노의 함성**: 주변 적 기절 + 자신 공격력 상승 |
| **마족** | 마력, 위험한 힘 | 지능 +3, 힘 +1, 체력 -1 | **암흑 친화**: 암흑 속성 피해 +15%, 성속성 피해 +10% 받음 | **마계의 계약**: 체력을 소모해 마나 전부 회복 |

> 밸런스 원칙: 모든 종족은 장점과 단점이 있으며, 특정 종족이 특정 클래스를 강제하지 않는다. (예: 오크 마법사, 엘프 전사도 유효한 빌드)

### 3.1 종족별 서사 차이
- **인간**: 왕도 중심의 정치 퀘스트가 풍부, 모든 마을에서 중립적으로 환영
- **엘프**: 숲 세력과 우호, 드워프와 초기 관계 냉랭
- **드워프**: 상점/제작 할인, 엘프 마을에서 초기 가격 불이익
- **오크**: 투기장 퀘스트 해금, 인간 도시 일부 구역에서 경계 대화
- **마족**: 일부 NPC가 적대적, 대신 암흑 계열 퀘스트와 숨겨진 루트 해금

## 4. 클래스 (Class)

### 4.1 기본 5클래스

| 클래스 | 역할 | 무기 | 주 능력치 | 조작 스타일 |
|---|---|---|---|---|
| **전사** | 근접 탱커/딜러 | 검, 도끼, 방패 | 힘, 체력 | 가드와 반격, 넉백 |
| **도적** | 근접 기동 딜러 | 단검, 쌍검 | 민첩 | 백어택, 연속기, 은신 |
| **마법사** | 원거리 광역 딜러 | 지팡이, 마도서 | 지능 | 차징, 속성 마법, 마나 관리 |
| **궁수** | 원거리 단일 딜러 | 활, 석궁 | 민첩 | 카이팅, 조준, 함정 |
| **성직자** | 서포터/회복 | 메이스, 성서 | 신앙(지능), 체력 | 힐, 버프, 성속성 공격 |

### 4.2 클래스별 스킬 (레벨 1~10 초기 구성)

**전사**
- 기본 공격: 3연타 콤보
- Q 방패 막기: 정면 피해 감소, 타이밍 맞추면 패링
- W 돌진 베기: 짧은 돌진 + 넉백
- E 전투 함성: 방어력 증가
- R 대지 가르기: 부채꼴 광역 피해

**도적**
- 기본 공격: 빠른 2연타
- Q 암습: 적 뒤로 순간이동 후 치명타
- W 독 바르기: 일정 시간 독 피해 부여
- E 연막탄: 은신 + 적 어그로 해제
- R 그림자 난무: 범위 내 연속 베기

**마법사**
- 기본 공격: 마력탄 (자동 조준 보조)
- Q 화염구: 폭발 광역
- W 빙결 지대: 둔화 장판
- E 순간 이동: 짧은 거리 블링크
- R 유성우: 지정 위치에 대규모 낙하

**궁수**
- 기본 공격: 방향 지정 사격 (차징 시 강화)
- Q 삼연사: 3방향 화살
- W 덫 설치: 밟으면 속박
- E 후퇴 사격: 뒤로 구르며 사격
- R 폭풍 화살비: 넓은 범위 지속 피해

**성직자**
- 기본 공격: 메이스 타격 + 성속성 추가 피해
- Q 치유의 빛: 자신/아군 회복 (싱글 플레이에선 소환수/NPC 동료 포함)
- W 성스러운 방벽: 짧은 무적 보호막
- E 정화: 상태이상 해제
- R 심판의 망치: 대상 주변 성속성 광역 + 언데드 추가 피해

### 4.3 확장 클래스 (후속 업데이트 후보)
- 전직 시스템: 전사 → 성기사/버서커, 도적 → 암살자/레인저, 마법사 → 원소술사/흑마법사, 궁수 → 저격수/사냥꾼, 성직자 → 사제/퇴마사
- 신규: 음유시인, 소환사, 연금술사

## 5. 능력치 및 성장 시스템

### 5.1 기본 능력치
| 능력치 | 효과 |
|---|---|
| 힘 (STR) | 물리 공격력, 무기 요구 조건, 적재 무게 |
| 민첩 (DEX) | 공격 속도, 회피율, 치명타율, 이동 속도 일부 |
| 지능 (INT) | 마법 공격력, 최대 마나, 마나 재생 |
| 체력 (VIT) | 최대 HP, 물리/상태이상 저항 |
| 신앙 (WIS) | 회복량, 성속성 피해, 버프 지속시간 |

### 5.2 파생 스탯 공식 (초안, 추후 테스트로 조정)
```
최대 HP   = 100 + VIT * 12 + 레벨 * 8
최대 MP   = 50  + INT * 8  + WIS * 3 + 레벨 * 4
물리 공격력 = 무기 공격력 + STR * 1.5 + DEX * 0.5
마법 공격력 = 무기 마력 + INT * 1.8 + WIS * 0.4
치명타율   = 5% + DEX * 0.2%  (최대 60%)
회피율     = 3% + DEX * 0.15% (최대 40%)
```

### 5.3 레벨 & 스킬 트리
- 최대 레벨: 50 (v1.0 목표)
- 레벨업 시 **자유 능력치 포인트 3** + **스킬 포인트 1** 획득
- 클래스별 스킬 트리 3갈래 (예: 마법사 = 화염 / 냉기 / 비전)
- 스킬은 최대 5레벨 강화 + 룬(변형 효과) 장착 가능

## 6. 전투 시스템 (액션)

### 6.1 기본 조작 (키보드 + 마우스 / 게임패드)
| 입력 | 동작 |
|---|---|
| 마우스 좌클릭 (바닥) | 클릭 지점으로 이동 (누르고 있으면 커서 방향으로 계속 이동) |
| 마우스 좌클릭 (적) | 대상 추적 + 기본 공격 (사거리 안에서 자동 반복 공격) |
| Space / A | 회피 구르기 (무적 프레임 0.2초) |
| Q, W, E, R | 스킬 (고정 슬롯, 마우스 커서 위치/방향으로 시전) |
| F | 상호작용 |
| 1, 2, 3 | 소모품 퀵슬롯 |
| Tab | 인벤토리/메뉴 |

### 6.2 전투 규칙
- 조준: 마우스 커서 위치/방향 (게임패드는 우스틱), 이동과 공격 모두 좌클릭으로 처리
- 회피: 스태미나 소모, 연속 사용 제한
- 속성: 물리 / 화염 / 냉기 / 번개 / 성 / 암흑 (상성 존재)
- 상태이상: 중독, 화상, 빙결(둔화), 기절, 속박, 침묵
- 적 패턴: 공격 전조(빨간 범위 표시) → 회피 가능한 설계
- 보스: 3페이즈 구조, 페이즈마다 패턴 추가

### 6.3 타격감 요소
- 히트스톱(0.05~0.1초), 카메라 흔들림, 피격 플래시
- 넉백 연출, 데미지 숫자 팝업, 치명타 별도 이펙트
- 효과음/타격음 레이어링

## 7. 게임 진행 구조

### 7.1 전체 흐름
```
타이틀 → 캐릭터 생성(종족/클래스/외형) → 프롤로그 → 마을(허브)
   → 필드 탐험 / 던전 / 퀘스트 → 보스 → 챕터 클리어 → 다음 지역
```

### 7.2 챕터 구성 (v1.0 목표)
| 챕터 | 지역 | 보스 | 목표 |
|---|---|---|---|
| 프롤로그 | 시작 마을 | - | 튜토리얼, 기본 조작 |
| 1장 | 솔라리온 평원/왕도 | 도적왕 | 왕관 행방의 단서 |
| 2장 | 실바넬 숲 | 타락한 정령 | 엘프와의 맹약 |
| 3장 | 아이언후드 광산 | 용광로 골렘 | 드워프의 협력 |
| 4장 | 붉은 평원 | 오크 대족장 | 오크 부족 통합 |
| 5장 | 균열의 땅 | 마왕 | 최종 결전 / 엔딩 분기 |

### 7.3 엔딩 분기 (후보)
- **왕관의 수호자**: 왕관을 되찾아 왕국을 재건
- **새로운 맹약**: 모든 종족이 합의한 연합 체제 수립
- **마왕의 계승**: 왕관과 마왕의 힘을 취하는 어두운 엔딩 (마족 루트에서 강화)

## 8. 아이템 & 경제

### 8.1 장비
- 부위: 무기, 방어구(머리/몸/장갑/신발), 방패/보조, 장신구 2
- 등급: 일반(흰) → 고급(초록) → 희귀(파랑) → 영웅(보라) → 전설(주황)
- 랜덤 옵션 + 세트 효과 + 소켓(룬/보석)

### 8.2 소모품
- 체력/마나 포션, 해독제, 버프 음식, 폭탄, 귀환 두루마리

### 8.3 경제
- 재화: 골드 (일반), 영혼석 (강화/특수 상점)
- 획득: 몬스터 드롭, 퀘스트 보상, 상자, 판매
- 사용: 상점 구매, 강화, 수리, 스킬 초기화, 제작

### 8.4 제작 & 강화
- 드워프 대장간: 무기/방어구 제작 및 강화
- 엘프 연금술: 포션 제작
- 강화 단계 +1~+10 (고단계 실패 시 하락 없음, 대신 재료 손실)

## 9. 몬스터 & 적 AI

### 9.1 몬스터 분류
| 분류 | 예시 | 특징 |
|---|---|---|
| 야생 | 늑대, 멧돼지, 거대 거미 | 단순 돌진/물기 |
| 인간형 | 산적, 도적단 궁수, 광신도 | 원거리/근접 혼합 |
| 언데드 | 해골 전사, 구울, 리치 | 성속성에 취약 |
| 정령/마수 | 불 정령, 숲의 수호수 | 속성 패턴 |
| 마족 | 임프, 마검사, 상급 악마 | 고위험 고보상 |

### 9.2 AI 구조
- FSM(유한 상태 머신): `Idle → Patrol → Chase → Attack → Retreat/Stunned`
- 감지 범위, 시야각, 어그로 해제 거리 설정
- 엘리트/보스는 Behavior Tree 또는 패턴 스크립트 방식 사용

## 10. 퀘스트 & NPC

- 메인 퀘스트: 챕터별 스토리 진행
- 서브 퀘스트: 마을 의뢰, 수집, 처치, 호위
- 종족 전용 퀘스트: 선택 종족에 따라 추가 퀘스트 해금
- 세력 평판: 인간 왕국 / 엘프 숲 / 드워프 길드 / 오크 부족 / 마족 군단
  - 평판에 따라 상점 가격, 대사, 퀘스트 접근성 변화
- 동료 NPC: 챕터 진행 중 합류 (최대 1명 동행, AI 제어)

## 12. 아트 & 사운드 방향

## 13. 기술 설계 (Unity)

### 13.1 환경
- Unity 2022 LTS 이상 (또는 Unity 6 LTS), **2D URP 템플릿**
- 핵심 패키지: **Input System, Cinemachine, 2D Pixel Perfect, Tilemap, 2D Animation, TextMeshPro, Addressables**
- 카메라: Pixel Perfect Camera (참조 해상도 320x180, PPU 16)

### 13.2 폴더 구조
```
Assets/
 ├─ _Project/
 │   ├─ Art/        (Sprites, Tilesets, Animations, UI)
 │   ├─ Audio/      (BGM, SFX)
 │   ├─ Data/       (ScriptableObjects)
 │   ├─ Prefabs/
 │   ├─ Scenes/
 │   ├─ Scripts/
 │   │   ├─ Core/        (GameManager, SaveSystem, EventBus)
 │   │   ├─ Character/   (Stats, Race, Class, Skill)
 │   │   ├─ Combat/      (Damage, Hitbox, StatusEffect)
 │   │   ├─ Enemy/       (AI, Spawner)
 │   │   ├─ Inventory/   (Item, Equipment)
 │   │   ├─ Quest/
 │   │   ├─ UI/
 │   │   └─ Utils/
 │   └─ Settings/
```

### 13.3 데이터 주도 설계 (ScriptableObject)
- `RaceData`: 능력치 보정, 패시브, 종족 스킬 참조
- `ClassData`: 기본 스탯, 사용 가능 무기, 스킬 트리
- `SkillData`: 쿨타임, 코스트, 피해 계수, 이펙트, 효과 리스트
- `ItemData`, `EnemyData`, `QuestData`, `DialogueData`
- 밸런싱은 코드 수정 없이 데이터만 바꿔서 가능하도록 한다.

### 13.4 핵심 시스템 클래스 (초안)
```
CharacterStats      // 기본/파생 스탯 계산, 버프 적용
RaceData / ClassData  // 종족·클래스 정의
ClickMoveController // 좌클릭 이동/공격 대상 판정, 경로 탐색(A*)
SkillController     // 스킬 입력(QWER), 쿨타임, 시전
DamageSystem        // 피해 계산, 속성 상성, 치명타
StatusEffectSystem  // 상태이상 관리
InventorySystem     // 아이템/장비 관리
QuestManager        // 퀘스트 진행도
SaveSystem          // JSON 기반 세이브/로드
EventBus            // 시스템 간 느슨한 결합
```

### 13.5 피해 계산 (초안)
```
최종 피해 = (공격력 × 스킬계수 − 방어력 × 0.5)
            × 속성 배율 × (치명타 ? 1.5 : 1) × 랜덤(0.95~1.05)
최소 피해 = 1
```

### 13.6 세이브 데이터
- 저장 항목: 종족/클래스/레벨/스탯, 인벤토리, 장비, 퀘스트, 맵 진행도, 평판
- 형식: JSON (`Application.persistentDataPath`), 추후 암호화/클라우드 검토
