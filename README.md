# Ashen Crown · 잿빛 왕관

중세 판타지 탑다운 픽셀 액션 RPG입니다. 기획서(`docs/GAME_DESIGN.md` 기준, 가제 *Ashen Crown*)의 1장 버티컬 슬라이스를 브라우저 게임으로 만들었습니다.
TypeScript + Canvas로 만들었고, 설치 없이 웹에서 바로 실행됩니다.

## 들어 있는 것

| 구분 | 내용 |
| --- | --- |
| 캐릭터 생성 | 종족 5 × 클래스 5 = 25조합, 외형 2종, 이름 |

| 클래스 | 전사·도적·마법사·궁수·성직자 — 기본 공격 + QWER 스킬 4개(최대 5레벨) |
| 전투 | 좌클릭 이동(A* 길찾기)·적 클릭 자동 공격, 구르기(무적 0.2초, 스태미나), 공격 예고(빨간 범위), 속성 상성, 상태이상(중독·화상·빙결·기절·속박), 히트스톱·화면 흔들림·데미지 숫자 |

| 지역 | 하스벨 마을(1장 허브), 솔라리온 평원, 잊혀진 지하 묘지(어두운 던전), 도적단 요새, 균열의 틈(1장 이후) |

| 기타 | 세이브 슬롯 3개(브라우저 저장소), 미니맵, 효과음·배경음(코드로 합성), 모바일 터치 지원 |

## 조작

| 입력 | 동작 |
| --- | --- |
| 좌클릭 (바닥) | 이동 (누르고 있으면 커서 방향으로 계속) |
| 좌클릭 (적 / NPC / 상자) | 공격 / 대화 / 열기 |
| 방향키 | 키보드 이동 |
| A | 인식한 적 공격 (가까운 적을 자동 인식, 청록색 표시) |
| Tab | 다른 적 인식 |
| Space | 회피 구르기 |
| Q W E R | 클래스 스킬 (커서 위치·방향) |
| T | 종족 스킬 |
| 1 2 3 | 소모품 |
| F | 상호작용 |
| I · C · K · J | 가방 · 능력치 · 스킬 · 퀘스트 |
| Esc | 메뉴 |

모든 키는 게임 안 ⚙ 설정(또는 타이틀의 설정)에서 바꿀 수 있습니다.

모바일: 화면을 탭해 이동·공격하고, 아래 버튼으로 스킬을 씁니다(가까운 적 자동 조준).

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

배포용 빌드는 `npm run build` 이고 결과물은 `dist/` 폴더입니다. 정적 파일이라 GitHub Pages, Netlify 등 어디에나 올릴 수 있습니다.

## 멀티플레이 방식

- 서버 없이 브라우저끼리 WebRTC로 직접 연결합니다. 처음 서로를 찾을 때만 PeerJS의 무료 공개 중계 서버(0.peerjs.com)를 씁니다.
- 방장 컴퓨터가 몬스터를 움직이고, 참가자는 자기 캐릭터를 움직이며 때린 피해를 방장에게 보냅니다.
- 회사·학교처럼 방화벽이 강한 망에서는 연결이 안 될 수 있습니다 (TURN 서버 없음).
- 개발 중 테스트: 주소 뒤에 `?net=local` 을 붙이면 같은 브라우저의 탭끼리 연결됩니다.
